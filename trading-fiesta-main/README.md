# Trading Fiesta

Crear una plataforma educativa para aprender trading estilo Duolingo, que tenga, curso por niveles, rachas diarias, insignias, quiz interactivos, desbloqueos progresivos en las lecciones, ranking de estudiantes, certificado, suscripción premium con un diseño moderno, compatible con móviles, tabletas y computadores.
